# dimos_worlds.dock: Dock 3-class station + M4D-class quadcopter

A drone docking station with two hinged covers driven by linear actuators, and the quadcopter that lives in it, as
generated meshes and a MuJoCo model. Both are generic models built to the dimensions DJI publishes for its Dock 3 and
Matrice 4D. They are not DJI products and are not affiliated with or endorsed by DJI. They carry no logos, marks or
third-party artwork. DJI, Dock 3 and Matrice are trademarks of their owner and appear here only to name the source of
the published dimensions.

No mesh file is committed. `shapes.py` builds every mesh with manifold3d from the numbers in `spec.json`. Each number
there carries its source:

| Label | Meaning |
|---|---|
| DJI | DJI spec page, FAQ or manual text (URLs in `spec.json` → `sources`) |
| DWG | read off DJI's dimensioned drawings in the installation manual (±2 mm) |
| FIT, DERIVED | solved from, or arithmetic on, DJI numbers and drawings |
| MEAS | measured on DJI's public product imagery through a camera solved from known DJI dimensions; the residual is in each note. No image is included |
| EST | estimate, UNVERIFIED |

## Files

```
spec.json         every number, with its source
shapes.py         every visible mesh (manifold3d CSG): base, body, pad, covers, gauges, RTK mast, quadcopter
geometry.py       frames, cover kinematics, actuator linkage, cameras, collision proxies, materials (plain Python)
gen_mjcf.py       writes assets/ (meshes, git-ignored) + dock.xml (scene) + dock_fixture.xml (attachable)
sim.py            DockSim: open/close covers, take off, fly to a point, land, camera feeds, state
fixture.py        attach_dock(spec, pos, yaw_deg, prefix): put the station into any MjSpec
check.py          envelopes vs DJI, cover timing, landing, penetration, off-pad contacts, close refusal
preview.py        MuJoCo preview sheet (overview + dock cameras at closed / half / open)
web_glb.py        web GLB (glTF 2.0 binary, no Blender): one node per body, covers_open animation
lot_example.py    optional: the station on the night lot's office roof, a round trip over row D
dock.xml, dock_fixture.xml   generated by gen_mjcf.py; the meshes they name are rebuilt on first use
```

## Run

Installed with dimos-worlds (`mujoco`, `numpy`, `pillow`, `manifold3d>=3.0`). No DimOS process is needed.

```
python -m dimos_worlds.dock.gen_mjcf                       # assets/ + dock.xml + dock_fixture.xml
python -m dimos_worlds.dock.check                          # JSON report, exit 1 on any failure
python -m dimos_worlds.dock.preview --out preview.jpg
python -m dimos_worlds.dock.fixture --env my_env.xml --pos 0 0 0 --yaw 90
python -m dimos_worlds.dock.lot_example                    # on the lot's office roof: open, fly, land, close
python -m dimos_worlds.dock.web_glb --out dock_station.glb   # ~1.8 MB, 68k triangles
```

The meshes are written to `assets/` next to the package on first use (git-ignored). Tests: `pytest tests/test_dock.py`.

```python
from dimos_worlds.dock.sim import DockSim
sim = DockSim()                      # builds the meshes on first use if assets/ is missing or stale
sim.open(); sim.run_until_idle()     # covers 0 -> 90 deg in 5 s
sim.takeoff(3.0); sim.land()         # launch and land on the pad with contact physics
jpeg = sim.feed_jpeg("dock_internal")
```

## Model

- Frame: origin on the ground under the station centre, +X toward the cover with the wind gauge, rain gauge and both
  station cameras, -Y = front (e-stop, cable ports, electrical cabinet, RTK mast), +Z up. The quadcopter parks nose
  toward +X.
- Bodies: `dock`, `cover_r` (+X), `cover_l`, `act_cyl_r|l`, `act_rod_r|l`, `drone` (free joint `drone_free`).
- Covers: hinges `cover_r_hinge`, `cover_l_hinge`, each driven by an integrated-velocity actuator (`cover_r_act`,
  `cover_l_act`) whose speed limit is exactly open angle / travel time. Each actuator is a closed chain (cylinder
  swing joint, rod slide joint, equality connect to the cover pin), so the linkage follows the cover in physics.
  `DockSim` refuses to close while the quadcopter is inside the sweep.
- Cameras: `dock_internal`, `dock_external` (equidistant fisheye, 151 deg diagonal; `lens="stream"` gives the
  dewarped view), `drone_wide` (rectilinear, 84 deg diagonal at 4:3), `overview` (scene only).
- Collision: boxes, cylinders, capsules and convex hulls per part (geometry.collision); visual meshes collide with
  nothing. Station geoms (contype 1, conaffinity 0) never touch each other; the quadcopter (contype 0,
  conaffinity 1) hits the station and anything else with contype 1. Host-env bodies with MuJoCo's default filter
  (1, 1) collide with the station.
- The quadcopter is held by a force/torque controller (thrust along body Z + attitude PD). It launches and lands with
  real contacts but is not a flight-dynamics model.

## Known limits

- Each cover swings on one fitted hinge. End poses match DJI's drawings; the path between them is approximate.
- Cover travel time (5 s) is an estimate: DJI publishes none.
- Open length is 1736 mm against DJI's 1760 mm: DJI's own drawings disagree by 12-19 mm on where the weather module
  sits when open.
- Pad floor height and the landing-pad block crest are MEAS ±15 mm. Depths behind the cabinet door, the quadcopter's
  lower body, belly and rear arm roots, and the parked prop pitch are estimates.
- Flat materials only, no textures.

## Web GLB

`web_glb.py` writes glTF 2.0 binary from the same meshes (manifold3d's `simplify()` on meshes over 4000 triangles,
surfaces within 0.4 mm) and the same linkage (MuJoCo poses every body). A root node `dock_station` turns Z-up into
glTF's Y-up, so a station-frame point (x, y, z) lands at (x, z, -y). Under it: `dock`, `cover_r`, `cover_l`,
`act_cyl_r`, `act_rod_r`, `act_cyl_l`, `act_rod_l`, `drone`, one mesh each with one primitive per material. The
rest pose is closed with the quadcopter parked. Animation `covers_open` runs closed to open over the travel time;
set its time from a cover angle (t = angle / open_deg x travel_s). The `drone` node has no channels, so a viewer can
fly it. The root's extras carry `open_deg`, `travel_s`, `close_clear_alt_m` and `drone_park`. Same input, same bytes.
